# Magnification accessibility station

An interactive demo showing why websites need to be designed for screen magnification, browser zoom, and larger text.

1. **Through the lens**: a simulated full-screen magnifier over a shop page. Try it with both fragile and magnifier-friendly feedback.
2. **Zoom to 400%**: compare a fixed-width layout with a responsive one (WCAG 1.4.10 Reflow).
3. **Turn up the text**: px units and fixed heights compared with relative units (WCAG 1.4.4, 1.4.12).
4. A design checklist and how to test.

It's a static site with no build step: `index.html`, `styles.css`, `app.js`. Deployed with GitHub Pages from `main`.

Created in [T3 Code](https://t3.codes).
